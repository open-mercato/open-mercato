covers the neutral filled Button and Basic Text Input. The references below are
the actual inspected nodes. A recorded component set does not mean that every
variant has been checked.

The application keeps its existing semantic palette, font stack and icon library.
The Inter toolbar option helps compare typography in the preview. It does not
change application fonts or imply complete visual parity. Figma's button set
also reports errors when reading its property definitions; its individual
variants remain inspectable. All 32 local Code Connect declarations now use verified
component-set IDs. Local parsing passes; online validation requires a Figma
plan/seat capability that is unavailable in this session. Nothing was published.
