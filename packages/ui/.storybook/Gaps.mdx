## How to read the source library

A related example means that working code exists for that family. It does not mean all
source axes or visuals are implemented. The differences listed on each page are the
**audit baseline**, before the follow-up fixes. Individual component stories show the
newly added capabilities; the baseline remains available as evidence of what the audit found.

The [measured Button/Input comparison](./?path=/docs/design-system-figma-comparison--docs)
records dimensions, corrected type/radius/spacing and remaining icon/font differences.
The Inter toolbar option changes the preview font without changing application tokens.

## Validation boundary

Examples use actual production components with local mock data. Browser checks exercise
keyboard focus, disabled states, portal themes, dismissal, real selection and narrow
layouts. They do not prove authentication, permissions, server loading or application
mutations. A full source-variant screenshot comparison remains separate work.

Changes live in the existing repository. No commit, push, Figma write or publication
has been made. Update the shared gallery registry and regenerate the catalogue to add
an example; generated Storybook and harness inventories are not edited by hand.
