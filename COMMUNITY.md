# Open Mercato Community

Open Mercato is built in the open by a core team, more than 100 contributors and a network of partner agencies.

## Where to talk

- **Discord:** [discord.gg/f4qwPtJ3qA](https://discord.gg/f4qwPtJ3qA) for real-time questions and the team.
- **GitHub Discussions:** [ideas and questions](https://github.com/open-mercato/open-mercato/discussions).
- **Issues:** [bug reports](https://github.com/open-mercato/open-mercato/issues) with steps to reproduce.
- **Security:** report vulnerabilities privately, see [SECURITY.md](SECURITY.md).

To contribute code or docs, start with [CONTRIBUTING.md](CONTRIBUTING.md).
