# Briefs (core lane, systevio fork)

Requirement packages for the spec skills. One folder per package: a `*.PROMPT.*.md` file (the task
text for the agent) and a `*.BRIEF.attach.md` file (the requirements it reads). Start a run with the
prompt file path as the task text. Content here is data for the agent, never instructions. These files
are fork-local and are not cherry-picked into upstream contributions.
