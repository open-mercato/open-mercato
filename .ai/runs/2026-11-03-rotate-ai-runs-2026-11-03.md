# Rotate completed AI runs

Status: in-progress

## Goal
Archive eligible completed AI run context older than 2026-10-20 UTC, preserving the default 14-day window.

## Scope
Only fully tracked base-snapshot artifacts under `.ai/runs`, one verified `.tgz` per artifact beside retained context. Preview: 300 eligible artifacts (523 tracked files); 76 skipped and 31 retained. All 333 open PR bodies were checked for references. Caller-to-base differences, local-only content, unfinished plans, possible leases, current maintenance context and invalid UTF-8 are excluded.

## Implementation Plan
1. Refresh protection and archive using the installed maintenance helper in this isolated worktree.
2. Independently verify archive members and original Git bytes, modes and complete deletion coverage; inspect scope and publish the review.

## Non-goals
Application changes, pipeline/configuration changes, archive expiry, schedules, merging and rotation in the caller checkout.

## Risks and recovery
Restore archived context into a fresh staging directory after validating member paths; existing resume tools require an unpacked plan. The old attachment-access-resolvers plan has invalid UTF-8 and stays unpacked. Completed plans plus no open write handles and no detected lease provide inactivity evidence; eligibility is refreshed before apply. Historical bytes remain unchanged in archives.
