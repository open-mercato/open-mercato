Pricing Engine — screen inventory

Interactive backend screens derived from .ai/specs/2026-08-21-pricing-engine.md (Phase 1 admin UI + optional Phase 3 diagnostic page). The shell, page scaffolding, DataTable chrome, and CrudForm layout mirror packages/ui/src/backend/; colors and spacing come from globals.css. The optimistic-lock conflict bar mirrors packages/ui/src/backend/conflicts/RecordConflictBanner.tsx verbatim (role, copy, token classes). Phase 2 (resolver registry hardening) and Phase 3's core resolver logic ship no UI of their own and are not represented here — only the optional diagnostic page is.
