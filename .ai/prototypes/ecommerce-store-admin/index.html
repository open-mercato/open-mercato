v1.0.0
1The dangling-binding diagnostic is the whole point of US-D2: without it, a store silently stops serving and the admin sees an unexplained failure with nothing on this page to connect it to.

4What a static screen cannot show: verification state is polled from customer_accounts, so a pending row can turn verified without anyone touching this page.
