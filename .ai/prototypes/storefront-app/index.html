Storefront App — screen inventory

Derived from .ai/specs/2026-08-14-storefront-app.md (§4 Route Tree, §5 Components, §6 Design System, §7 Responsive). Deliberate scope exception: om-mockup-prototype is written for backend/backoffice flows and explicitly routes storefront work elsewhere — this prototype exists anyway, at the requester's explicit request, kept intentionally small (4 screens, desktop only, no account/checkout). It uses the same click-through/comment tooling as the backend prototypes but a storefront chrome (top nav, not the AppShell sidebar), per §6's own token table (page title text-4xl font-light tracking-tight, container max-w-7xl) rather than packages/ui/src/backend/ patterns. This spec has no User Stories section of its own (§4/§5/§6 are architecture, not stories), so screens are cited directly against those sections instead of story ids.
