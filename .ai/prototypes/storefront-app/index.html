Storefront app — screen inventory

Five storefront pages in eight states, derived from .ai/specs/2026-08-14-storefront-app.md and its §16 story map. Storefront chrome, not the backend AppShell — this is a deliberate, explicitly requested exception to om-mockup-prototype’s backend scope, kept small: desktop only, no account area, no checkout funnel.

Screens 2–4 are the same listing under three server answers, because §5.4a’s rule is only visible in the difference between them: options come from the response’s availableSorts, the control shows appliedSort, and a sort the server declined produces the catalogue with a note rather than an error. The admin side of that policy is the ecommerce-store-admin prototype, screens 12–13.
