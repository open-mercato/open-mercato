Studio: lookups

Admin maintains tables that map a choice to a value, a SKU or a list of allowed options.
1
Typed lookupsA lookup has a friendly name and maps each option of one feature to a value, a SKU or a list of allowed options.
2
Catalog checkSKU values are checked against the catalog when a row is edited; unknown or ambiguous SKUs are marked. Validate runs the same check on the saved draft.
3
CoveragePublishing checks that every option of the key feature has a row, so a missing row cannot drop a part silently.
4
Bulk editsAdvanced (JSON) is the supported path for large changes; spreadsheet paste is not in v1.
5
Permitted lookupPer key value: which options are allowed (toggle chips) and which one is the default; the default must be allowed.
