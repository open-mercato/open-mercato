# Installation

Every guide below is **self-contained** — it covers all prerequisites, infrastructure setup, and every command from zero to a running app. No jumping back and forth.

## Choose your path

### 📦 Standalone app — build your own app (start here)

Scaffold a standalone project that pulls Open Mercato packages from npm. Your modules, overrides, and customisations live in your repo while the core stays untouched and upgradeable. This is the right path for building a product on Open Mercato and for trying it for the first time.

| Platform | |
|---|---|
| 🍎 macOS | [Open guide →](./standalone#macos) |
| 🐧 Linux | [Open guide →](./standalone#linux) |
| 🪟 Windows | [Open guide →](./standalone#windows) |

:::tip Working with an AI coding agent?
Let `create-mercato-app` set up the agent harness (the wizard asks, or pass `--agents claude-code`, `codex`, `cursor` or `all`), then ask your agent to use the **`om-help`** skill. It maps what you want to build to the right guides and skills in your app.
:::

### 🔧 Monorepo — contribute to the core

Clone the full platform source to contribute to the core, work on framework features, or run a complete local demo. You do not need it to build your own app.

| Platform | |
|---|---|
| 🍎 macOS | [Open guide →](./monorepo#macos) |
| 🐧 Linux | [Open guide →](./monorepo#linux) |
| 🪟 Windows | [Open guide →](./monorepo#windows) |

### 🐳 Docker dev setup — full stack in containers

Run the entire stack inside Docker with hot reload. No local Node.js or Yarn required. Works on any OS; on Windows it is slower than the native path.

[Open guide →](./docker)

### 🚀 VPS / production deployment

Deploy a production-ready Docker stack to any Linux server or VPS.

[Open guide →](./vps)

### 🛠️ Dev Container — zero-install VS Code environment

Open the repo in a fully pre-configured container. Docker Desktop + VS Code is all you need.

[Open guide →](./devcontainer)

### ☁️ Railway - CLI-managed cloud deployment

Deploy a standalone app with `mercato deploy railway`. The repeatable CLI flow provisions PostgreSQL, Redis, the app service, an optional worker, environment variables, and a public domain.

[Open guide →](/deployment/railway)
