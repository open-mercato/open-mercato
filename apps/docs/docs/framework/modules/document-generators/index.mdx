# Document Generators

`@open-mercato/document-generators` provides server-side PDF rendering, a template registry, preview and download UI, and an extension API for templates contributed by other modules.

The package includes templates for sales orders and quotes. Additional modules can register templates through the `document-generators.ts` convention file and can embed the template picker in their own widget slots.

## What the module provides

- server-side rendering with `@react-pdf/renderer`
- built-in order invoice and sales offer templates
- live PDF preview and download
- generation history scoped by tenant and organization
- a registry for templates contributed by other modules
- reusable React-PDF theme and logo components
