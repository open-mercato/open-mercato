# Document Generators

`@open-mercato/document-generators` provides PDF and Markdown rendering, a template registry, preview and download UI, and an extension API for templates contributed by other modules.

The package is domain-independent. Sales owns the order and quote templates and registers them through its `document-generators.ts` convention file. Other modules can use the same convention and embed the template picker in their own widget slots.

## What the module provides

- server-side PDF rendering with `@react-pdf/renderer` and Markdown rendering
- Sales-provided order invoice and sales offer templates, registered through module code generation
- live preview and download
- generation history scoped by tenant and organization
- a registry for templates contributed by other modules
- reusable React-PDF theme and logo components
