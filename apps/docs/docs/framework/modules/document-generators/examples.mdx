# Document Generators Examples

Working reference implementation showing how to add custom document templates to your `@open-mercato/*` module.

Copy the structure below into your own module and adjust names, data shapes, and template layout.

## File layout

```
your-module/
  document-generators.ts                          ← convention file, picked up by `mercato generate registry`
  document-generators/
    services/
      my-module-invoices-document-service.ts ← extends BaseDocumentService
    templates/
      invoice/
        my-invoice/
          types.ts                           ← data shape for the template
          pdf/
            index.tsx                        ← React-PDF component
  widgets/                                   ← optional — only needed for custom slots (see step 6)
    injection/
      document-generators-order-tab/
        widget.ts                            ← InjectionWidgetModule descriptor
        widget.client.tsx                    ← renders <TemplatesList>
    injection-table.ts                       ← declares which slot gets the widget
```

## Quick-start checklist

1. Copy `invoice/` → rename to your category (`quote/`, `shipment/`, etc.)
2. Rename `ExampleInvoice*` → your own prefix
3. Edit `types.ts` to match the data available in your widget context (`context.record`)
4. Implement `toTemplateData()` in the service to map the fetched record to your template types
5. Design the template layout in `index.tsx`
6. *(Optional)* To embed the template picker in a **custom slot**, copy `widgets/` and update the slot key in `injection-table.ts`. Sales already owns widgets for `sales.document.detail.order:tabs` and `sales.document.detail.quote:tabs`, so adding another widget at either spot would produce duplicate tabs.
7. Run `yarn generate` to pick up the new `document-generators.ts` entry
