# Installation

## Step-by-step

**1. Add the package** to your Open Mercato application:

```bash
yarn mercato module add @open-mercato/document-generators
```

**2. Register the module** in `src/modules.ts`:

```ts
{ id: 'document_generators', from: '@open-mercato/document-generators' }
```

**3. Regenerate** the module registry so templates contributed by enabled modules are picked up:

```bash
yarn generate
```

**4. Grant permissions** — new features are automatically added to default roles on the next `yarn generate` run. To sync existing tenants manually:

```bash
yarn mercato auth sync-role-acls
```

---

## Verification

When both `sales` and `document_generators` are enabled, navigate to a sales order or quote detail page. A **Documents** tab contributed by Sales appears automatically. Selecting a template opens a format-appropriate preview and download action.

If the tab does not appear, confirm that:

- The module is listed in `src/modules.ts`
- The `sales` module is enabled when verifying the shipped Sales integration
- `yarn generate` was run after registration
- The current user's role has the `document_generators.view` feature
