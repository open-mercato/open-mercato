# Currencies and Exchange Rates

The currencies module provides comprehensive multi-currency and exchange rate management with automatic fetching from external providers. It's built on a flexible, extensible architecture that supports custom rate providers and multiple sourcing strategies.

## Architecture Overview

```
┌─────────────────────────┐
│  ExchangeRateService    │  ← High-level, business-focused API
│  (Get rates with        │     - Database-first retrieval
│   automatic fetching)   │     - Automatic provider fallback
└───────────┬─────────────┘     - Daily fallback (up to 30 days)
            │
            ▼
┌─────────────────────────┐
│  RateFetchingService    │  ← Low-level, provider orchestration
│  (Fetch and store)      │     - Manages provider lifecycle
└───────────┬─────────────┘     - Batch processing
            │                    - Error tracking
            ▼
┌─────────────────────────┐
│   Rate Providers        │  ← External data sources
│   (NBP, Raiffeisen,     │     - Pluggable architecture
│    Custom providers)    │     - Standardized interface
└─────────────────────────┘
```

## Database Schema

### Currency Entity

Stores currency metadata with multi-tenant scoping:

```typescript
@Entity()
export class Currency {
  @PrimaryKey()
  id: string

  @Property()
  code: string // ISO 4217 code (e.g., "USD")

  @Property()
  name: string

  @Property({ nullable: true })
  symbol?: string

  @Property({ default: 2 })
  decimalPlaces: number

  @Property({ nullable: true })
  thousandsSeparator?: string

  @Property({ nullable: true })
  decimalSeparator?: string

  @Property({ default: false })
  isBase: boolean // One base currency per organization

  @Property()
  tenantId: string

  @Property()
  organizationId: string

  @Property()
  isActive: boolean

  @Property()
  createdAt: Date

  @Property({ onUpdate: () => new Date() })
  updatedAt: Date
}
```

Key indexes:
- `(tenant_id, organization_id, code)` – Unique constraint, ensures one currency per code per org
- `(tenant_id, organization_id, is_base)` – Fast base currency lookup
- `(tenant_id, organization_id, is_active)` – Active currency queries

### ExchangeRate Entity

Stores directional exchange rates with source attribution:

```typescript
import { ExactDecimalType } from '@open-mercato/shared/lib/db/exactDecimalType'

@Entity()
export class ExchangeRate {
  @PrimaryKey()
  id: string

  @Property()
  fromCurrencyCode: string

  @Property()
  toCurrencyCode: string

  @Property({ type: ExactDecimalType, columnType: 'numeric' })
  rate: string // Unconstrained decimal string, never rounded to a fixed scale

  @Property()
  date: Date

  @Property()
  source: string // Provider identifier (e.g., "NBP", "Raiffeisen", "manual")

  @Property({ nullable: true })
  type?: 'buy' | 'sell' // Bank's perspective

  @Property({ type: 'jsonb', nullable: true })
  metadata?: Record<string, unknown> | null // Free-form context, e.g. the NBP table number

  @Property()
  tenantId: string

  @Property()
  organizationId: string

  @Property()
  isActive: boolean

  @Property()
  createdAt: Date

  @Property({ onUpdate: () => new Date() })
  updatedAt: Date
}
```

Key indexes:
- `(tenant_id, organization_id, from_currency_code, to_currency_code, date, source)` – Fast pair lookups
- `(tenant_id, organization_id, date)` – Date-based queries
- `(tenant_id, organization_id, source)` – Provider-based filtering

## Service Layer

### ExchangeRateService

High-level API for retrieving exchange rates with automatic fetching and fallback.

#### Dependency Injection

```typescript
import type { ExchangeRateService } from '@open-mercato/core/modules/currencies/services/exchangeRateService'

const exchangeRateService = container.resolve<ExchangeRateService>('exchangeRateService')
```

#### Single Rate Retrieval

```typescript
import { decimalToString, multiplyDecimals } from '@open-mercato/shared/lib/decimal'

const result = await exchangeRateService.getRate({
  fromCurrencyCode: 'USD',
  toCurrencyCode: 'EUR',
  date: new Date('2024-01-15'),
  scope: {
    tenantId: 'tenant-123',
    organizationId: 'org-456',
  },
  options: {
    maxDaysBack: 30,      // Look back up to 30 days (default)
    autoFetch: true,      // Fetch from providers if not found (default)
  },
})

// Result structure
interface RateResult {
  rates: ExchangeRate[]
  fromCurrencyCode: string
  toCurrencyCode: string
  requestedDate: Date
  actualDate: Date | null
  error?: Error
}

if (result.rates.length > 0) {
  const convertedAmount = decimalToString(multiplyDecimals('100', result.rates[0].rate))
}
```

#### Batch Retrieval

```typescript
const results = await exchangeRateService.getRates({
  pairs: [
    { fromCurrencyCode: 'USD', toCurrencyCode: 'EUR' },
    { fromCurrencyCode: 'GBP', toCurrencyCode: 'PLN' },
    { fromCurrencyCode: 'EUR', toCurrencyCode: 'JPY' },
  ],
  date: new Date(),
  scope: { tenantId, organizationId },
})

// Results is a Map<string, RateResult>
for (const [key, result] of results.entries()) {
  if (result.error) {
    console.error(`Failed to get ${key}: ${result.error.message}`)
  } else if (result.rates.length > 0) {
    console.log(`${key}: ${result.rates[0].rate}`)
  } else {
    console.log(`${key}: No rates found`)
  }
}
```

#### Daily Fallback

If a rate isn't found for the requested date, the service automatically:
1. Checks the database
2. Fetches from providers if `autoFetch=true`
3. Recursively checks previous days (up to `maxDaysBack`)
4. Returns `actualDate` to indicate which date was used

#### Date Validation

- **Allowed**: Today and all historical dates
- **Rejected**: Future dates (throws error)

```typescript
// ✅ Valid
await exchangeRateService.getRate({
  fromCurrencyCode: 'USD',
  toCurrencyCode: 'EUR',
  date: new Date(), // Today
  scope: { tenantId, organizationId },
})

// ❌ Throws error
const tomorrow = new Date()
tomorrow.setDate(tomorrow.getDate() + 1)
await exchangeRateService.getRate({
  fromCurrencyCode: 'USD',
  toCurrencyCode: 'EUR',
  date: tomorrow,
  scope: { tenantId, organizationId },
})
```

```typescript

  { tenantId: 'tenant-123', organizationId: 'org-456' }
```

#### When to Use Each Service

| Use Case | Service |
|----------|---------|
| Business logic needing rates | ExchangeRateService |
| Currency conversions | ExchangeRateService |
| Scheduled/batch fetching | RateFetchingService |
| Admin operations | RateFetchingService |
| Automatic fallback needed | ExchangeRateService |
| Explicit control over fetching | RateFetchingService |

## Rate Providers

### Built-in Providers

#### NBP (National Bank of Poland)

```typescript
import { NBPProvider } from '@open-mercato/core/modules/currencies/services/providers/nbp'

const provider = new NBPProvider()
```

- **Currencies**: ~13 major currencies (USD, EUR, GBP, CHF, etc.)
- **Rate types**: Bid (buy) and Ask (sell)
- **Data source**: National Bank of Poland Table C
- **Updates**: Daily, published by central bank
- **API**: Public REST API

#### Raiffeisen Bank Polska

```typescript
import { RaiffeisenPolandProvider } from '@open-mercato/core/modules/currencies/services/providers/raiffeisen'

const provider = new RaiffeisenPolandProvider()
```

- **Currencies**: EUR, USD, CHF, GBP
- **Rate types**: Buy and Sell
- **Data source**: Web scraping from public rate tables
- **Updates**: Multiple times per day (intraday rates)
- **Method**: HTML parsing

### Creating Custom Providers

Implement the `RateProvider` interface:

```typescript
import type { RateProvider, RateProviderResult } from '@open-mercato/core/modules/currencies/services/providers/base'

export type ProviderRate = {
  from: string
  to: string
  value: string
  reference?: string
  type?: 'buy' | 'sell'
}

export class MyCustomProvider implements RateProvider {
  readonly name = 'MyProvider'
  readonly source = 'MyProvider'

  constructor(private readonly fetchFromApi: (
    date: Date,
    scope: { tenantId: string; organizationId: string },
  ) => Promise<ProviderRate[]>) {}

  isAvailable(): boolean {
    return true
  }

  async fetchRates(
    date: Date,
    scope: { tenantId: string; organizationId: string },
    availableCurrencies: Set<string>,
  ): Promise<RateProviderResult[]> {
    const rates = await this.fetchFromApi(date, scope)
    return rates
      .filter(rate => availableCurrencies.has(rate.from) && availableCurrencies.has(rate.to))
      .map(rate => ({
        fromCurrencyCode: rate.from,
        toCurrencyCode: rate.to,
        rate: rate.value,
        source: this.source,
        date,
        type: rate.type,
        metadata: { reference: rate.reference },
      }))
  }
}
```

#### Register Custom Provider

```typescript
import { asFunction } from 'awilix'
import type { AppContainer } from '@open-mercato/shared/lib/di/container'
import type { RateFetchingService } from '@open-mercato/core/modules/currencies/services/rateFetchingService'
import { MyCustomProvider } from './providers/myCustomProvider'
import { fetchRatesFromApi } from './providers/myProviderApi'

export function register(container: AppContainer) {
  container.register({
    myCurrencyRateProvider: asFunction(() => new MyCustomProvider(fetchRatesFromApi)).singleton(),
  })
  container.resolve<RateFetchingService>('rateFetchingService')
    .registerProvider(container.resolve<MyCustomProvider>('myCurrencyRateProvider'))
}
```

## REST API

### Currencies

```
GET    /api/currencies/currencies              List currencies
POST   /api/currencies/currencies              Create currency
PUT    /api/currencies/currencies              Update currency (id in body)
DELETE /api/currencies/currencies?id=<uuid>    Delete currency
```

Query parameters for GET:
- `page`, `pageSize` - Pagination
- `search` – Filter by code or name
- `isActive` – Filter by active status
- `isBase` – Filter base currency

### Exchange Rates

```
GET    /api/currencies/exchange-rates              List rates
POST   /api/currencies/exchange-rates              Create rate
PUT    /api/currencies/exchange-rates              Update rate (id in body)
DELETE /api/currencies/exchange-rates?id=<uuid>    Delete rate
```

Query parameters for GET:
- `page`, `pageSize` - Pagination
- `fromCurrencyCode` – Filter by source currency
- `toCurrencyCode` – Filter by target currency
- `id` - Filter by rate ID
- `isActive` - Filter by active status
- `source` – Filter by provider
- `type` – Filter by rate type (buy/sell)

### Fetch Configuration

```
GET    /api/currencies/fetch-configs              List provider configs
POST   /api/currencies/fetch-configs              Enable provider
PUT    /api/currencies/fetch-configs              Update config (id in body)
DELETE /api/currencies/fetch-configs?id=<uuid>    Delete config
```

### Trigger Manual Fetch

```
POST   /api/currencies/fetch-rates    Fetch rates for a date
```

Request body:
```json
{
  "date": "2024-01-15",
  "providers": ["NBP"]
}
```

The module uses command/query separation. Pass an authenticated, organization-scoped command context. The example assumes EUR already exists in that scope:

```typescript

async function createCurrencyAndRate(ctx: CommandRuntimeContext, scope: {
  tenantId: string
  organizationId: string
```

## Data Validation

All inputs are validated using Zod schemas:

```typescript
import { currencyCreateSchema, exchangeRateCreateSchema } from '@open-mercato/core/modules/currencies/data/validators'

// Currency validation
const currencyData = currencyCreateSchema.parse({
  code: 'USD',
  name: 'US Dollar',
  symbol: '$',
  // ...
})

// Exchange rate validation
const rateData = exchangeRateCreateSchema.parse({
  fromCurrencyCode: 'USD',
  toCurrencyCode: 'EUR',
  rate: '0.92',
  // ...
})
```

Key validation rules:
- **Currency codes**: 3 uppercase letters (ISO 4217)
- **Rate values**: Positive plain decimal strings, with at most 1000 significant digits, 300 integer digits, and no non-zero digit below `1e-1000`; stored without a fixed fractional scale
- **Currency decimal places**: Integer from 0 to 50
- **Exchange-rate metadata**: Optional JSON object or null, limited to 16 KB of UTF-8 JSON
- **Source**: 2-50 alphanumeric characters, spaces, hyphens, underscores
- **Dates**: Truncated to minute precision

## Example: Currency Conversion Utility

```typescript
import type { ExchangeRateService } from '@open-mercato/core/modules/currencies/services/exchangeRateService'
import { decimalToString, multiplyDecimals } from '@open-mercato/shared/lib/decimal'

export async function convertCurrency(
  exchangeRateService: ExchangeRateService,
  amount: string | number,
  fromCode: string,
  toCode: string,
  date: Date,
  scope: { tenantId: string; organizationId: string },
  options?: {
    preferredProvider?: string
    rateType?: 'buy' | 'sell'
  }
): Promise<string | null> {

  const result = await exchangeRateService.getRate({
    fromCurrencyCode: fromCode,
    toCurrencyCode: toCode,
    date,
    scope,
  })

  if (result.rates.length === 0) {
    return null // No rate available
  }

  // Filter by preferences
  let selectedRate = result.rates[0]

  if (options?.preferredProvider) {
    const providerRate = result.rates.find(r => r.source === options.preferredProvider)
    if (providerRate) selectedRate = providerRate
  }

  if (options?.rateType) {
    const typeRate = result.rates.find(r => r.type === options.rateType)
    if (typeRate) selectedRate = typeRate
  }

  return decimalToString(multiplyDecimals(amount, selectedRate.rate))
}

// Usage
const exchangeRateService = container.resolve<ExchangeRateService>('exchangeRateService')
const eurAmount = await convertCurrency(
  exchangeRateService,
  '100',
  'USD',
  'EUR',
  new Date(),
  { tenantId: 'tenant-123', organizationId: 'org-456' },
  { preferredProvider: 'NBP', rateType: 'sell' }
)
```
