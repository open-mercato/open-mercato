# Runtime Security Profile

Open Mercato keeps the compatibility default:

```bash
OM_AI_RUNTIME_SECURITY_PROFILE=standard
```

Set the profile to `hardened` when AI operations must stop if their safety checks or evidence trail are unavailable:

```bash
OM_AI_RUNTIME_SECURITY_PROFILE=hardened
```

In the MIT AI framework this profile:

- disables the legacy OpenCode Code Mode chat endpoint;
- enforces input moderation in text and structured object modes;
- rejects a model call when its provider cannot perform the required moderation check;
- keeps mutation tools behind the existing pending-action confirmation flow;
- encrypts pending inputs, field diffs, batch diffs, summaries, and execution results through tenant data encryption.

The hardened profile can reduce availability. A moderation or encryption outage stops the affected AI operation by design. Configure a moderation-capable provider, tenant encryption, and enough human review capacity before enabling it.
